# Security Policy / 安全政策

## English

This repository is an engineering baseline, not a safety-certified machining advisory service. Do not use example cutting parameters or inferred compatibilities for physical operations.

If you discover a security vulnerability, avoid public disclosure of exploit details or private records. Contact the repository owner through a private vulnerability-reporting channel when one is configured. **No dedicated contact address is currently published.** Do not put credentials, access tokens, internal catalog extracts, customer data, personal or educational information in issues, logs or fixtures.

## 简体中文

本项目尚非经安全认证的现场加工推荐系统。不得直接使用示例加工参数或推测出的兼容关系执行实际设备操作。

如果发现安全漏洞，请在仓库配置私人漏洞报告渠道后向维护方私下反馈，不要公开利用细节或敏感数据。**目前尚未公布专用安全联系地址。** 不得在Issue、日志和数据样本中包含凭据、内部目录、客户数据、个人信息或学校信息。
